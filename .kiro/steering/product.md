# Product Overview

在庫番（Zaikoban）は、家庭・個人向けの「備蓄」管理 Web アプリケーションです。日用品・食品・消耗品などのストックを、場所と箱で整理し、買い物リストと連動させて切らさない運用を支援します。

## Core Capabilities

- 備蓄アイテムの一覧・検索・詳細表示
- 「使う・補充・買い物」アクションによる在庫操作
- 場所・箱（location / box）による収納整理と入力補助
- 買い物リストとの連携（不足→買い物、購入→補充）
- 写真による識別・記録

## Target Use Cases

- 家庭の日用品・食品・防災備蓄の可視化と切らし防止
- 何がどこにどれだけあるかの把握
- 買い物時の「何が必要か」を即座に判断

## Value Proposition

シンプルで使いやすい UI で、家庭の備蓄を「見える化」し、買い物と補充の判断を迷わせません。モバイル操作を最優先に、PC でも崩れない表示を提供します。

## Design Principles

- **モバイルファースト**: スマホでの片手操作を最優先設計とし、PC 表示は調整対応
- **空状態を丁寧に**: 空状態 UI・リトライ導線・トーストで操作フィードバックを明示
- **最小操作で完了**: 使う / 補充 / 買い物 の主要アクションは 1〜2 タップで到達
